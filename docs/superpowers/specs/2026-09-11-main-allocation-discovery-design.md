# Main 가로 배분 요약과 하단 탐색

사용자 승인: 2026-09-11 대화. Main 도넛을 가로 배분 막대로 대체하고 `자세히 보기`는 버튼과 내부 영역 모두 제거한다. Simulation 진입점은 페이지 끝에서 더 탐색할 때 드러낸다.

## 현재 계약

- 하나의 요약 표면에 왼쪽은 월수입 대비 저축·투자 합계율, 오른쪽은 저축:투자 비율, 32px 가로 막대와 지출·저축·투자·여윳돈 금액 행을 표시한다.
- 월수입 금액을 처음부터 드러내는 부담을 피하기 위해 요약과 그래프 접근성 설명에서 수입 금액을 직접 표시하지 않는다. 오른쪽 비율은 저축·투자 합계 100 기준(예: 60 : 40)이며 한쪽 0원은 0 : 100 또는 100 : 0, 모두 0원은 미설정이다.
- 금액 행은 실제 월수입 대비 비율과 금액을 항상 제공하며 기존 편집기·지출 도우미·분배 도우미를 유지한다. hover, keyboard focus, touch 선택은 해당 막대 구간을 강조한다.
- 막대는 정상 상태에서 수입을 전체로 사용한다. 적자는 전체 배분을 화면 폭에 맞추고 실제 수입 위치에 기준선을 표시한다. 실제 비율은 수입 기준으로 유지한다. 음수 여윳돈을 양수 조각으로 만들지 않는다.
- 0원 항목은 막대에서 생략하되 목록은 남긴다. 작은 금액에 최소 시각 폭을 강제하지 않는다. 월수입 0원은 비율을 표시하지 않는다.
- `자세히 보기` disclosure, 내부 제목·막대·중복 표를 완전히 제거한다. 최초 설정 review의 AllocationBar와 데이터 계약은 유지한다.
- Simulation 진입점은 처음에는 시각적으로 숨긴다. 페이지 끝에서 시작한 추가 wheel 제스처(220ms 이상 간격, 누적 64px) 또는 위쪽 swipe(56px)로 드러낸다. 페이지 끝으로 도착하는 기존 제스처와 내부 스크롤·편집 맥락에서는 드러내지 않는다.
- 키보드 Tab으로 버튼에 초점을 옮기면 즉시 노출한다. `이 계획을 계속하면?` 안내와 `미래 성장 보기` 버튼을 표시하며 자동 이동하지 않는다. 노출 후에는 안정적으로 유지한다. 새 페이지 진입 시 숨김 상태로 시작하며 별도 저장은 없다.
- 모바일 하단 편집 바와 겹치지 않게 노출 위치를 확보한다. reduced-motion에서는 막대·진입점 전환과 부드러운 스크롤을 생략한다. 기존 런처 탐색은 유지한다.

## 참고한 패턴

- [Apple 저장 공간](https://support.apple.com/en-mide/guide/mac-help/mchl3d437fbc/mac): 전체의 배분과 남는 공간.
- [Monarch Flex Budgeting](https://help.monarch.com/hc/en-us/articles/32125337244052-Using-Flex-Budgeting): 금액과 초과 상태를 막대 가까이에 배치.
- [YNAB 목표 추적](https://www.ynab.com/features/goal-tracking): 막대와 항목 정보를 연결. Main은 소비 실적·목표 달성률이 아닌 계획 배분을 표현한다.

## 대체 범위와 검증

이 문서는 기존 2026-08-03 도넛 요약 spec의 시각화·정보 순서·상세 영역 및 2026-08-06 모바일 도넛 상호작용 spec을 대체한다. 기존 계산·저장·편집 소유권은 변경하지 않는다. 도넛 전용 렌더러·원호 geometry·hit test·motion과 관련 전용 테스트는 가로 막대의 비례·적자·입력 상호작용 검증으로 대체한다.

검증은 `npm run check`, Main·JourneyEntryCard 단위 테스트와 Main·app-journey Playwright를 실행한다. 390px, 768px, 1280px의 overflow, 44px 조작 영역, 편집 focus 복원, 적자 전체 표시, 추가 wheel/touch 노출과 키보드·reduced-motion 동작을 확인한다.
