# 초과 리퀴드 표현과 재설정 집중 화면 설계

> **부분 대체:** `5:1` 길이 압축, 최대 10% gutter와 연속 liquid·droplet 표현은 [Anime.js 공통 모션 시스템 설계](2026-08-12-animejs-motion-system-design.md)가 대체한다. 재설정 집중 화면과 나머지 interaction 계약은 유지한다.

## 목적

월수입을 넘은 금액을 바깥으로 흘러나온 영역처럼 직관적으로 표현한다. 초과율이 커질수록 가로 길이와 움직임이 자연스럽게 강화되어야 하지만, 기존 월수입 바의 크기와 모바일 레이아웃은 흔들리지 않아야 한다.

저장된 계획에서 `처음부터 다시 설정`을 선택한 동안에는 현재 입력 작업에 필요하지 않은 앱 메뉴와 다음 앱 안내를 숨긴다. 기존 값과 취소 경로는 보존한다.

## 범위

### 포함

- 수입 대비 초과율에 비례하는 가로 돌출 영역
- 초과율의 압축 표시와 최대 너비
- 초과 구간별 리퀴드 속도와 물방울
- 움직임 감소 환경의 정적 표현
- 재설정 화면의 앱 런처 및 Simulation 진입 안내 숨김
- 최초 설정, 재설정, 대시보드의 노출 회귀 테스트

### 제외

- 자금 계산식 변경
- 표의 종류, 금액, 비율 정보 변경
- 설정 단계나 저장 형식 변경
- 앱 간 `JourneySnapshot` 계약 변경
- Simulation 준비 화면 변경

## 초과 영역의 공간 모델

월수입 `100%`를 나타내는 기존 바의 길이를 항상 `100`으로 유지한다. 초과 영역은 바 내부를 다시 나누거나 바의 높이를 키우지 않는다. 연결부가 끊겨 보이지 않도록 월수입 바의 `98` 지점에서 시작해 마지막 길이 `2`를 겹친 뒤, 오른쪽 끝을 지나 카드 또는 구성 요소의 시각 경계를 의도적으로 벗어난다.

초과율은 실제 비율보다 `5:1`로 압축해 표시한다.

```ts
overflowRatio = deficitWon / incomeWon
overflowPercent = overflowRatio * 100
displayLength = min(max(overflowPercent, 0), 50) / 5
liquidLength = 2 + displayLength
```

예:

- 초과 `10%`: 겹침 길이 `2` + 돌출 길이 `2` = 전체 리퀴드 길이 `4`
- 초과 `15%`: 겹침 길이 `2` + 돌출 길이 `3` = 전체 리퀴드 길이 `5`
- 초과 `30%`: 겹침 길이 `2` + 돌출 길이 `6` = 전체 리퀴드 길이 `8`
- 초과 `50% 이상`: 겹침 길이 `2` + 돌출 길이 `10` = 전체 리퀴드 길이 `12`

`10%`마다 길이 `2`인 한 구간으로 계산하지만 화면에는 딱딱한 칸 경계를 노출하지 않는다. `15%`처럼 구간 사이 값은 길이 `3`으로 연속 보간한다.

리퀴드 전체 길이는 기존 월수입 바 길이의 `2%`부터 `12%`까지다. 이 중 바깥으로 돌출되는 최대 표시 너비는 기존과 동일한 `10%`다. 초과가 있을 때만 레이아웃에 돌출 공간을 확보해 390px 모바일에서도 문서 가로 스크롤을 만들지 않는다. 총 계획이 월수입의 `100%` 이하이면 돌출 공간을 제거하고 원본 바를 가용 영역의 좌우 중앙에 둔다. 카드 경계 밖으로 나오는 연출은 허용하지만 viewport 밖으로 잘리거나 다른 핵심 콘텐츠를 덮지 않는다.

수입이 0원인 경우 초과율을 계산할 수 없으므로 돌출 길이 애니메이션은 표시하지 않는다. 기존 표와 텍스트가 금액 상태를 설명한다.

## 리퀴드 시각 언어

초과 영역은 기존 바와 같은 높이를 유지한다. 세로 팽창, 큰 압력 마개, 반복 줄무늬는 제거한다.

표현 원칙:

- 월수입 바 마지막 `2%`를 덮으며 이어지는 액체 형태
- 겹침 구간은 투명 그라데이션으로 기존 바 색과 자연스럽게 혼합
- 낮은 대비의 그라데이션과 미세한 광택
- 값 변경 시 약 `450ms`의 spring 계열 easing
- 길이 변화와 흐름 속도의 급격한 단절을 막는 보간
- 구성 요소를 압도하지 않는 낮은 진폭

초과 구간:

- `0% 초과 ~ 10% 미만`: 느리고 잔잔한 흐름
- `10% 이상 ~ 30% 미만`: 흐름 속도 증가
- `30% 이상 ~ 50% 미만`: 빠른 흐름과 작은 물방울 1~2개
- `50% 이상`: 길이는 `10`으로 고정하고 최고 흐름 속도와 작은 물방울 유지

물방울은 초과율 `30%`부터만 나타난다. 바 아래로 짧게 분리되었다가 사라지며 페이지 높이나 주변 배치를 바꾸지 않는다. 과도한 튐, 폭발, 큰 입자는 사용하지 않는다.

`prefers-reduced-motion: reduce`에서는 흐름, spring, 물방울 애니메이션을 제거한다. 정적인 돌출 길이, 색, 표, 초과 안내 문구만으로 같은 정보를 전달한다.

## 적용 위치

동일한 초과 강도 계산을 재사용 가능한 표현 모델로 분리한다.

- 빠른 설정의 `FlowContextSummary`
- 검토 화면의 `AllocationBar`

두 구성 요소는 같은 초과율, 표시 길이, 구간을 사용한다. 각 구성 요소가 임의의 CSS 강도를 별도로 결정하지 않는다. 표의 종류, 금액, 수입 대비 비율과 터치·호버 상세 정보는 현재 동작을 유지한다.

### 6/6 검토 표 정렬

모바일 6/6 검토 화면에서 표와 `AllocationBar` 카드의 좌우 여백은 동일해야 한다. 초과 돌출 공간을 확보하기 위한 오른쪽 여백을 표, 카드 또는 전체 `AllocationBar`에 적용하지 않는다.

- 표와 카드는 가용 폭 전체를 사용하고 가운데 정렬된 것처럼 보여야 한다.
- 모바일 카드의 좌우 내부 padding은 `12px`다.
- 카드 배경은 현재 값을 변경하지 않고, 반투명 회색 `1px` hairline 테두리만 사용한다.
- 테두리는 표보다 강하게 보이지 않아야 하며 그림자나 이중 경계는 추가하지 않는다.
- `종류` 열은 왼쪽, `금액`과 `수입 대비` 열은 오른쪽 정렬을 유지한다.
- 초과 돌출용 최대 `10%` 공간은 상단 시각 바 요소만 소유한다.
- 바의 오른쪽 공간 확보가 표의 폭, 열 위치 또는 카드 좌우 여백에 영향을 주지 않는다.
- 390px에서 카드의 왼쪽·오른쪽 화면 여백 차이는 1px 이하여야 한다.

## 재설정 집중 화면

`MainState`의 기존 정보로 화면을 구분한다.

- 최초 설정: `state.mode === 'setup' && state.applied === null`
- 재설정: `state.mode === 'setup' && state.applied !== null`
- 대시보드: `state.mode === 'dashboard'`

별도 영속 상태나 새 저장 필드를 추가하지 않는다.

### 재설정 중

- `ISF 앱 메뉴`를 렌더링하지 않는다.
- `Simulation으로 이어가기` 카드와 안내를 렌더링하지 않는다.
- 저장된 계획을 복제한 기존 입력값을 유지한다.
- `취소`를 표시해 저장된 대시보드로 돌아갈 수 있게 한다.
- 설정 단계, 검증, 진행 상황 저장, 적용 동작은 유지한다.

### 최초 설정 중

- 기존 앱 메뉴를 유지한다.
- Main 계획이 필요하다는 비활성 Simulation 안내를 유지한다.
- 최초 사용자는 Main 입력 흐름만 수행한다.

### 재설정 종료 후

재설정을 적용하거나 취소해 대시보드로 돌아오면 앱 메뉴와 활성 가능한 Simulation 진입 안내를 다시 표시한다.

## 접근성 및 반응형

- 초과 정보는 애니메이션만으로 전달하지 않는다.
- 표와 `role="status"` 초과 금액 문구를 유지한다.
- 돌출 영역은 장식 요소로 처리해 접근성 트리에 중복 정보를 만들지 않는다.
- 390px와 768px에서 문서 가로 스크롤이 생기지 않는다.
- 키보드 포커스, 바 터치·호버 상세 정보, 최소 44px 입력 영역을 유지한다.
- 재설정 화면에서 숨긴 요소는 CSS로만 가리지 않고 렌더링하지 않아 포커스 순서에서도 제외한다.

## 오류 처리

- 수입이 0원이거나 비정상 계산 결과면 돌출 시각화를 숨기고 기존 텍스트 정보를 사용한다.
- 음수 또는 유한하지 않은 초과율은 표시 길이 `0`으로 방어한다.
- `50%`를 넘는 초과는 실제 금액과 비율을 표에 그대로 표시하고 시각 길이만 제한한다.
- 재설정 저장 실패 시 현재 입력값, 설정 화면 격리, 재시도 행동을 유지한다.

## 테스트 전략

### 단위 및 컴포넌트

- 초과율 `0%, 10%, 15%, 30%, 50%, 80%`의 표시 길이
- 초과가 있을 때 시작점 `98%`, 겹침 길이 `2%`, 전체 리퀴드 길이 `2 + displayLength`
- 총 계획이 월수입의 `100%` 이하일 때 오른쪽 돌출 여백 없음
- `50%` 초과 시 길이 제한과 실제 텍스트 비율 보존
- 수입 0원과 비정상 값의 안전한 처리
- `30%` 미만 물방울 없음
- `30%` 이상 물방울 있음
- 두 초과 바가 동일한 표현 모델 사용
- 6/6 모바일 표와 카드의 좌우 여백 차이 1px 이하
- 모바일 카드 좌우 padding `12px`와 투명 회색 `1px` 테두리
- 상단 시각 바의 돌출 공간이 표 너비와 열 정렬에 영향 없음
- 재설정 중 앱 메뉴와 Simulation 안내 없음
- 재설정 중 기존 입력값과 취소 버튼 있음
- 최초 설정 중 앱 메뉴와 비활성 Simulation 안내 있음
- 대시보드 복귀 후 앱 메뉴와 Simulation 안내 있음

### E2E

- 저장된 계획에서 재설정을 시작하면 기존 값이 채워지고 집중 요소만 표시
- 재설정 취소 후 대시보드 여정 요소 복구
- 재설정 적용 후 대시보드 여정 요소 복구
- 390px와 768px에서 최대 `50%` 초과 표현이 가로 스크롤을 만들지 않음
- reduced motion 환경에서 물방울과 흐름 애니메이션 없음

## 완료 기준

- 월수입 바 길이와 높이가 초과 여부와 무관하게 유지된다.
- 초과 영역이 월수입 바의 `98%` 지점부터 겹쳐 시작하고 오른쪽 경계 밖으로 자연스럽게 돌출된다.
- 초과율 `10%`당 기존 바 길이 `2`로 연속 표시되고 `50%`에서 길이 `10`으로 제한된다.
- 전체 리퀴드 길이는 겹침 `2`를 포함해 `2~12`이며, 바깥 돌출 길이는 기존 `0~10`을 유지한다.
- 총 계획이 월수입의 `100%` 이하이면 초과용 여백 없이 원본 바의 좌우 여백이 대칭이다.
- `30%` 이상에서만 절제된 물방울이 표시된다.
- 초과 강도가 두 Main 바에서 일관된다.
- 모바일에 문서 가로 스크롤이 생기지 않는다.
- 6/6 모바일 표는 좌우 대칭 여백, `12px` 내부 padding, 투명 회색 `1px` 테두리와 기존 열 정렬을 유지한다.
- 재설정 중 앱 메뉴와 Simulation 안내가 포커스 순서를 포함해 완전히 제외된다.
- 최초 설정과 대시보드의 기존 여정 안내는 유지된다.
