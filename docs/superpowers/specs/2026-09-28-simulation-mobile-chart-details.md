# Simulation 모바일 그래프 하단 상세

- 날짜: 2026-09-28
- 범위: Simulation 그래프의 모바일 탐색과 선택값 표시
- 기준: [PRD](../../ways-of-work/plan/isf-rebuild/connected-financial-planning-workspace/prd.md), [DESIGN](../../../DESIGN.md)
- 사용자 요청: 그래프 위 표기를 단순화하고 하단 공간에 상세 정보를 분리한다. 웹의 기존 tooltip 경험은 유지한다.

## 문제와 결정

기존 모바일 tooltip이 SVG 위에서 pointer를 받아 재터치를 가로막았다. 선택 지점 위의 카드가 곡선도 덮었다. 모바일에서는 상세 정보 영역을 그래프 아래의 일반 문서 흐름으로 옮긴다.

## 화면·탐색 계약

- 767px 이하: 그래프에는 선택 기준선과 현재 계획·전부 저축의 두 점만 표시한다. 떠 있는 tooltip은 렌더링하지 않는다.
- 하단 첫 줄은 선택 기간과 현재 계획 총액, 다음 두 열은 누적 납입원금·전부 저축 총액·저축 잔액·투자 잔액이다.
- 선택 전·해제 후에도 마지막 시점의 상세값을 유지해 영역 높이가 바뀌지 않는다. 0년은 `현재`, 단기 기간은 기존 월별 정밀도를 따른다.
- 가로 드래그와 재터치로 탐색하고 손을 떼거나 pointer가 취소되면 마지막 선택을 유지한다. 세로 swipe는 페이지 스크롤을 허용하고 스크롤·영역 밖 pointer·Escape는 선택을 해제한다.
- 하단 상세 정보와 별개인 최종 기간 비교에는 `N년 기준 비교`를 표시한다. 선택 시점에 따라 최종 비교값을 다시 계산하지 않는다.
- 768px 이상: 기존 상세 tooltip 배치·정보량·pointer·keyboard 동작을 유지한다.
- 키보드 Home·End·방향키와 screen reader 상태는 선택값 전체를 제공한다. 금액은 기존 한국식 정수 표현이며 임의 글자 단위 줄바꿈이나 잘림 없이 읽힌다.

## 구현 경계

`GrowthChart`의 단일 선택 상태와 기존 series를 공유한다. `GrowthChartDetails`는 선택값 또는 마지막 시점값을 표시하며 별도 저장 상태를 만들지 않는다. 그래프의 Anime.js 진입·변경 모션은 유지하고 드래그마다 새 애니메이션을 시작하지 않는다. 금융 계산·명목/실질 변환·Main 읽기 전용 경계·저장 schema는 변경하지 않는다.

## 인수 조건

- 320px·390px 실제 브라우저 touch 이벤트에서 연속 드래그·release·재터치·cancel·세로 scroll을 검증한다.
- 그래프 아래 정보 영역은 탐색 중 위치·높이가 유지되고, 금액이 잘리거나 화면이 가로로 넘치지 않는다.
- 390px·768px·1280px 큰 원금 화면, overlay containment, 키보드 탐색·Escape, touch target, 명목/실질·단기 월별 계산 회귀를 확인한다.
- 탐색만으로 workspace 저장값을 변경하지 않는다.
