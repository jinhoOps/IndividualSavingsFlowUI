# Main 모바일 도넛 상호작용 설계

## 목적

Main 대시보드의 월 자금 구성 도넛을 모바일에서 한눈에 읽고 직접 터치할 수 있게 한다. 좁은 범례에서 금액과 여백 때문에 명칭이 줄바꿈되는 문제를 없애면서 색상과 항목의 연결은 유지한다.

## 범위

- Main 대시보드 `CashflowDonutSummary`
- 모바일 범례의 정보 밀도와 용어
- 도넛 pointer·touch·keyboard 선택 상태
- 선택 상태의 중앙 정보와 시각 피드백

계산식, Main 저장 schema, Financial Detail Modal, 핵심 카드와 Allocation Bar는 변경하지 않는다.

## 모바일 범례

- 모바일 범례는 현재 2열 배치를 유지한다.
- 각 항목은 `색상 점 · 명칭 · 비율`만 한 줄로 표시한다.
- 금액은 모바일 범례에서 숨기고 desktop 범례에는 유지한다.
- 색상 점은 8px, 점과 명칭 사이 간격은 4px를 기준으로 사용한다.
- 범례 버튼의 최소 높이는 44px를 유지한다.
- 색상 점, 명칭과 비율은 같은 행에 표시하며 명칭이 줄바꿈되지 않게 한다.
- 사용자 용어는 `소비`, `저축`, `투자`, `여윳돈`으로 통일한다. 내부 allocation id `remaining`은 변경하지 않는다.

## 도넛 직접 탐색

- 도넛 링의 pointer 또는 touch 위치를 중심점 기준 각도로 환산해 해당 allocation을 선택한다.
- 선택 판정은 표시 비율과 누적 순서를 사용하므로 폭이 좁은 조각도 별도의 44px SVG target을 만들지 않고 링 전체에서 탐색할 수 있다.
- 도넛의 빈 중앙과 링 바깥은 조각 선택을 발생시키지 않는다.
- 범례의 tap·click·focus와 도넛 직접 선택은 하나의 `active allocation` 상태를 공유한다.
- keyboard 사용자는 기존 44px 범례 버튼으로 모든 항목을 탐색한다.
- 도넛 바깥 영역을 누르면 고정 선택을 해제하고 기본 중앙 요약으로 돌아간다.

## 선택 피드백

- 기본 중앙 정보는 기존처럼 저축·투자 합계 비율과 `저축·투자` 명칭을 표시한다.
- 항목 선택 중에는 중앙을 선택 항목 명칭과 월소득 대비 비율로 교체한다. 예: `56.3%`, `소비`.
- 선택 조각은 나머지 조각보다 바깥쪽으로 약 2px 확장하고 stroke를 소폭 굵게 표시한다.
- 선택 변화에는 짧고 절제된 transition을 적용한다.
- `prefers-reduced-motion`에서는 확장과 중앙 정보 전환을 즉시 완료한다.
- hover, focus와 고정 tap 선택은 같은 조각 강조와 중앙 정보를 사용한다.

## 상세 정보와 접근성

- 모바일 범례에서 숨긴 금액은 접근 가능한 이름과 선택 tooltip에 계속 제공한다.
- tooltip은 `명칭 · 금액 · 비율` 형식을 유지한다.
- SVG의 접근 가능한 요약은 네 항목의 명칭과 비율을 유지한다.
- 선택된 범례 버튼은 `aria-pressed`로 고정 선택 상태를 노출한다.
- 도넛 직접 선택 후에도 범례 버튼과 tooltip 연결을 통해 동일한 상세 정보를 보조기기에 제공한다.
- 월소득이 0인 안내 상태에서는 도넛 직접 탐색을 제공하지 않는다.

## 반응형

- 모바일 기준은 390px이며 범례 네 항목 모두 명칭 줄바꿈과 가로 overflow가 없어야 한다.
- 768px과 desktop에서는 기존 금액 정보를 유지하되 선택 조각과 중앙 정보 동작은 동일하게 제공한다.
- 범례의 pointer·touch target은 모든 viewport에서 최소 44px 높이를 유지한다.

## 검증

### 단위 테스트

- 모바일용 금액 표시 요소와 desktop용 금액 표시 계약
- 범례 click·focus 시 중앙 정보, tooltip와 조각 선택 class
- 같은 범례 재선택과 바깥 pointer 시 고정 선택 해제
- 도넛의 소비·저축·투자·여윳돈 각도 선택
- 도넛 중앙과 링 바깥 입력 무시
- `aria-pressed`와 접근 가능한 금액 정보

### Playwright

- 390px에서 `색상 점 · 명칭 · 비율` 네 항목이 한 줄이며 범례 높이가 44px 이상인지 확인
- 390px에서 도넛 네 영역을 터치해 중앙 명칭·비율과 선택 조각 확장을 확인
- 도넛 바깥 touch 후 기본 저축·투자 중앙 요약 복귀
- 768px과 desktop에서 금액 표시, hover·focus와 기존 tooltip 유지
- 모든 필수 viewport에서 가로 overflow 부재
- reduced-motion에서 선택 transition 제거

## 제외 범위

- 도넛 계산이나 구간 분류 변경
- 저축·투자 합계 구간별 신규 스타일
- 투자:저축 구간별 신규 스타일
- 핵심 카드의 정보나 편집 흐름 변경
- 도넛 drag 또는 연속 scrub 탐색
