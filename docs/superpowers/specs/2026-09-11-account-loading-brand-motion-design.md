# 앱 실행과 Main 재시작의 브랜드 모션

상태: 2026-09-11 후속 사용자 정정 반영. 로그인 성공 시점만 기준으로 삼던 계약을 아래 두 진입으로 수정한다.

## 재생 시점

1. 브라우저/PWA의 새로운 실행 탭에서 최초 진입할 때. 인증 확인과 workspace 조회를 동시에 시작하고 브랜드 장면을 독립적인 시작 화면으로 표시한다. 로딩 애니메이션으로 사용하지 않는다. 로그인하지 않은 사용자는 로그인 화면으로, 로그인된 사용자는 검증된 계획 또는 최초 계획 선택 화면으로 이어진다.
2. Main 관리 메뉴 `처음부터 다시` 확인창에서 `다시 시작`을 확정했을 때. 같은 확인창의 `초기화`로 빈 재시작 초안을 만든 경우도 같은 진입 장면을 사용한다. 확인창만 열거나 취소할 때는 재생하지 않는다.

같은 실행 탭의 Main ↔ Simulation ↔ Portfolio ↔ Account Map 이동, 새로고침, 설정 재개, 로그인 완료·Google callback·재인증에서는 브랜드 화면 자체를 표시하지 않는다. 400ms 이상 조회가 지연될 때만 작은 상태 문구를 표시하며 정지된 큰 로고도 사용하지 않는다. 저장된 setup을 재개할 때는 Main 재시작 장면이 반복되지 않는다.

## 수명과 접근성

- 기존 SVG geometry를 한 번 조립하며 최대 2.2초의 짧은 시작 장면을 제공한다. 화면 누르기·44px 건너뛰기 버튼·Escape로 일찍 종료할 수 있다.
- 인증·workspace 조회는 장면과 병렬로 진행한다. 장면은 조회 완료와 무관하게 종료하며 완성 로고를 대기 화면으로 남기지 않는다. 아직 조회 중이면 로고 없는 중립 배경을 거쳐 400ms 후 상태 문구를 표시한다. 빠른 전환에는 상태 문구도 잠깐 끼어들지 않는다. 시각 장면을 건너뛰어도 인증이나 데이터 검증을 우회하지 않는다.
- Main 재시작은 장면 종료 후 기존 setup welcome으로 넘어간다. 적용 계획·도우미 삭제 여부·다른 앱 데이터의 소유권은 변경하지 않는다.
- reduced motion은 장면을 건너뛰고 정상 조회/로그인/setup 흐름으로 진입한다. 모션 실패에도 종료 타이머·건너뛰기가 작동한다. 장면 unmount 때 모션과 타이머를 정리한다.
- 시작 장면의 건너뛰기에 초점을 두며, 이어지는 로그인·복구 heading 또는 Main setup heading으로 초점을 옮긴다. 로고는 장식 SVG다. 390px, 768px, desktop에서 장면·문구·버튼을 viewport 안에 둔다.

## 실행 구분과 저장 호환성

`AccountWorkspaceGate`가 기존 `getAccountTabId`로 확정한 탭 식별자와 `sessionStorage`의 `isf-brand-entry-tab`을 비교한다. 첫 진입 때만 표시 이력을 기록한다. 탭 복제는 기존 Web Locks의 새 탭 식별자를 사용하므로 다른 탭에서 본 이력을 그대로 적용하지 않는다. 계정 캐시 식별자가 변경되어도 Navigation Timing의 reload/back_forward 또는 이전 history가 있는 같은 origin 내부 이동이면 재생하지 않는다. 캐시 격리용 Web Locks 계약은 바꾸지 않는다. StrictMode effect 재실행은 문서 내 동일 결정을 재사용한다. 저장소 차단 시 같은 origin referrer에서는 반복 로고를 피한다.

기존 `isf-login-loading-once`는 Google callback이 같은 실행의 연속임을 알리는 60초 일회성 표식으로 소비·삭제한다. 계정 식별자나 금융 payload를 추가 저장하지 않으며 workspace schema·RPC·계정 캐시 계약은 변경하지 않는다. 구 클라이언트가 새 표식을 무시해도 저장 데이터에는 영향이 없다.

Main bootstrap의 fresh/resume/restart 메타데이터는 기존 진행 저장 계약을 유지한다. Main UI는 현재 재시작 entry ID의 장면 완료만 메모리에 보관한다. 별도 새 시작/빈 백업 복원 장면은 추가하지 않는다.

## 회귀 기준

- 로그인된 실행·로그인하지 않은 실행, 빠른/느린 응답, 로그인 완료·OAuth 연속 진입.
- 실제 앱 메뉴 링크로 네 앱 왕복 시 로고 DOM의 일시 mount도 없음. 새로고침·뒤로 가기도 반복 없음. 캐시 ID 변경·표식 누락 상황에서도 검증한다.
- Main 재시작 확인/취소/확정, 장면 건너뛰기와 heading focus, 저장된 설정 재개.
- reduced motion, 실패한 조회의 복구 화면, 키보드/터치, 390/768/1280px containment.
