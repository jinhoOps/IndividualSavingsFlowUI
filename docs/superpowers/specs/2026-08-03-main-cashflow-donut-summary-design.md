# Main Cashflow Donut Summary Design

## 목적

Main 첫 화면에서 월 실수령액 자체보다 월소득 대비 소비·저축·투자 비율을 먼저 이해하게 한다. 도넛은 관계 요약을 담당하고, 기존 핵심 카드는 정확한 금액 확인과 Financial Detail Modal 진입을 담당한다.

## 정보 순서

Main의 기본 순서는 다음과 같다.

1. 월 자금 구성 도넛 요약
2. 소비·남는 돈·저축·투자 핵심 카드
3. Simulation CTA
4. 자세히 보기 안의 기존 색상 막대와 종류·금액·비율 표

월 실수령액 핵심 카드는 제거한다. 소비·남는 돈·저축·투자 카드는 유지하며 일반 재무 편집은 기존 Financial Detail Modal만 사용한다.

## 도넛 표현

- 도넛 항목은 소비·저축·투자·남는 돈이다.
- 모든 비율은 실제 월소득을 분모로 계산한다.
- 소비는 따뜻한 색상, 저축과 투자는 서로 구분되는 차가운 색상, 남는 돈은 옅은 회색을 사용한다.
- 중앙에는 저축과 투자 합계의 월소득 대비 비율을 큰 숫자로 표시한다.
- 중앙의 `저축·투자` 설명과 `소득 초과` 상태는 작은 글씨로 표시한다.
- 월소득 금액은 중앙에 표시하지 않는다.
- 각 항목은 터치·호버·키보드 포커스 시 종류·금액·월소득 대비 비율을 표시한다.
- 색상만으로 의미를 전달하지 않고 텍스트 범례와 접근 가능한 전체 설명을 제공한다.
- 월소득이 0이면 도넛 대신 월소득 입력 안내를 표시한다.
- 계획 총액이 월소득을 초과하면 도넛은 100%까지만 채우고 실제 비율과 `소득 초과` 상태는 유지한다. 초과의 상세 시각화는 기존 AllocationBar가 담당한다.
- reduced-motion에서는 전환 없이 최종 상태를 표시한다.

## 상세 영역

기존 AllocationBar와 표를 제거하지 않고 `자세히 보기` 아래에 둔다. 상세 영역은 기본적으로 접혀 있으며 사용자가 펼치면 기존 종류·금액·비율, 툴팁과 초과 애니메이션을 그대로 제공한다.

## 계산 기반

계산은 UI와 분리된 `cashflowInsight` 모듈에서 제공한다.

### 저축·투자 합계율

- `(월 저축액 + 월 투자액) / 월소득`으로 계산한다.
- 향후 시각 변화에 사용할 수 있도록 `50% 미만`, `60% 미만`, `70% 미만`, `80% 미만`, `90% 미만`, `90% 이상` 구간값을 함께 제공한다.
- 이번 범위에서는 구간값에 따른 스타일 변화가 없다.

### 투자:저축 비율

저축액을 분모로 투자액 비율을 계산하고 다음 7단계로 분류한다.

1. `1:3 미만` — 투자 0원 포함
2. `1:3 구간`
3. `1:2 구간`
4. `1:1 구간`
5. `2:1 구간`
6. `3:1 구간`
7. `3:1 초과` — 저축 0원 포함

중간 5단계는 대표 비율 `1/3, 1/2, 1, 2, 3`에 가장 가까운 값으로 분류하고 인접 대표 비율의 산술 중간값을 경계로 사용한다. 투자와 저축이 모두 0원이면 `미설정`을 반환한다. 이번 범위에서는 이 구간값에 따른 스타일 변화가 없다.

## 구성 요소

- `CashflowDonutSummary`: 도넛, 중앙 합계율, 범례와 항목 상호작용을 담당한다.
- `cashflowInsight`: 도넛 비율, 저축·투자 합계 구간과 투자:저축 구간을 계산한다.
- `CashflowSummary`: 월 실수령액 카드를 제거하고 네 편집 카드를 유지한다.
- `AllocationBar`: 기존 동작을 유지하며 상세 disclosure 안에서 렌더링한다.

## 검증

- 계산 단위 테스트: 정상 값, 월소득 0, 계획 100% 초과, 합계율 10% 구간, 투자:저축 7단계 경계와 양쪽 0원
- 컴포넌트 테스트: 중앙 비율, 범례, 터치·호버·포커스 상세, 소득 초과와 0원 안내
- Dashboard 테스트: 월 실수령액 카드 제거, 도넛 우선 순서, 핵심 카드 편집과 상세 disclosure
- Main E2E: 기존 편집·적용·저장 흐름, 상세 막대와 표, reduced-motion
- Orca Browser: 390px, 768px와 desktop의 overflow, 첫 화면 순서, 터치 대상과 도넛 가시성
