# Main 설정 집중 화면과 검토 전환 설계

## 목적

Main의 1/6~6/6 설정 과정에서는 현재 입력에만 집중하도록 설정 카드 밖의 앱 메뉴와 연결 안내를 숨긴다. 6/6 검토 화면에서는 앞 단계의 단순 현금흐름 바가 최종 배분 바와 표로 자연스럽게 이어지도록 한다.

## 화면 경계

- 최초 설정과 기존 계획 재설정 모두 1/6~6/6에서 설정 카드만 주요 화면으로 표시한다.
- 앱 런처, Simulation 진입 안내 등 설정과 무관한 요소는 표시하지 않는다.
- 기존 계획 재설정의 `취소`는 이탈 안전장치이므로 설정 카드 내부 우측 상단에 유지한다.
- 진행률 바는 카드 상단 경계에 붙이지 않고 내부 여백을 둔 둥근 트랙으로 표시해 잘린 인상을 없앤다.
- 저장 실패나 진행 저장 실패처럼 작업 완료에 필요한 경고는 설정 카드 내부에 표시한다.

## 금액 빠른 조정 버튼

- 1/6~6/6 설정 카드의 금액 입력은 `-50만`, `-10만`, `+10만`, `+50만` 버튼을 한 줄에 표시한다.
- 네 버튼은 사용 가능한 너비를 같은 비율로 나누는 4열 그리드를 사용한다.
- 390px에서도 줄바꿈하지 않으며 버튼 사이 간격과 좌우 padding만 압축한다.
- 각 버튼의 높이는 최소 44px을 유지한다.
- 이 배치 변경은 설정 카드에만 적용하고 대시보드 편집 화면의 `MoneyField` 배치는 변경하지 않는다.

## 6/6 전환 연출

1. 6/6 진입 직전까지 표시하던 단순 `flow-bar`의 시각적 복제 레이어를 만든다.
2. 6/6의 제목과 화면을 인지할 수 있도록 350ms 동안 정지한다.
3. 복제 레이어가 검토 표 위의 `allocation-bar__visual-track` 위치로 이동한다.
4. 이동 중에는 단색 채움을 유지한다.
5. 도착 후 단색 레이어만 300ms 동안 서서히 투명해져 아래의 소비·저축·투자·잔액 색상 구간을 드러낸다.
6. 투명 전환이 끝나면 전환 레이어와 기존 단순 `flow-bar`를 제거한다.
7. 최종 `allocation-bar`와 배분 표는 전환 중 동일 위치에 유지되어 교체되는 인상을 만들지 않는다.
8. 뒤로 이동했다가 6/6에 다시 진입하면 연출을 다시 실행한다.

최종 상태에는 색상 구분된 배분 바와 표만 남으며 단순 `flow-bar`는 존재하지 않는다.

## 구현 경계

- 설정 단계 전환 상태는 `SetupFlow`가 소유한다.
- 최종 배분 수치와 색상 구간 계산은 기존 `AllocationBar` 계약을 재사용한다.
- 전환 전용 레이어는 표현만 담당하며 클릭, 포커스, 접근성 트리에 참여하지 않는다.
- 실제 데이터나 저장 흐름은 변경하지 않는다.
- 애니메이션 종료 여부와 관계없이 최종 DOM은 동일해야 한다.

## 접근성과 모션

- `prefers-reduced-motion: reduce`에서는 전환 레이어 없이 최종 배분 바와 표를 즉시 표시한다.
- 전환 레이어는 `aria-hidden="true"`와 비활성 포인터 동작을 사용한다.
- 표와 배분 정보의 읽기 순서는 기존 접근성 구조를 유지한다.
- 키보드 단계 이동, 오류 포커스, 재설정 취소 동작을 보존한다.

## 검증

- 단위 테스트: 설정 중 런처·연결 안내가 없고 재설정 취소는 카드 내부에 존재한다.
- 단위 테스트: 6/6 최종 DOM에는 단순 `flow-bar`가 없고 배분 바와 표가 존재한다.
- 브라우저 테스트: 1/6~6/6의 집중 화면, 6/6 전환 완료 상태, 뒤로 이동 후 재실행을 확인한다.
- 반응형 테스트: 390px, 768px, desktop에서 카드와 전환 레이어가 가로로 넘치지 않는다.
- 반응형 테스트: 390px 설정 화면에서 네 금액 조정 버튼이 같은 행에 있고 각 높이가 44px 이상이다.
- 모션 감소 테스트: 애니메이션 없이 최종 상태가 즉시 표시된다.
