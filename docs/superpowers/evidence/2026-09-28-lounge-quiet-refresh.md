# 라운지 상단 압축·30초 백그라운드 갱신

## 변경

- `LoungeApp.tsx`, `lounge.css`: 반복 제목·영문 장식 제거, 닉네임·공유 버튼을 한 줄로 압축. 스크린리더 제목·진입 초점은 보존하고 탐색 도구 영역을 유지한다.
- `useLoungeRefresh.ts`: 보이는 온라인 화면에서 30초 주기, 요청 중복 방지·숨김/오프라인 일시 정지·복귀 시 한 번 갱신·해제 후 정지.
- `LoungeApp.tsx`, `refreshPublications.ts`: 맨 위의 비조작 상태에서 최신 페이지를 교체한다. 이미 읽은 오래된 구간은 연결 가능한 커서일 때 유지하고 새 글 급증으로 빈 구간이 생기면 최신 페이지부터 더 보기를 이어 누락을 막는다. 스크롤 중 목록 순서를 유지한다.
- `useLoungeCommunity.ts`: 보이는 카드·열린 상세만 조용히 읽고 직접 공감 요청·늦은 응답·초점을 보호한다. 로딩·일시 실패 표시로 화면을 흔들지 않는다.
- `PublicationComments.tsx`: 첫 댓글 페이지의 맨 위에서 미작성 상태일 때 조용히 읽는다. 작성·삭제 확인·페이지 탐색을 시작하면 늦은 응답도 적용하지 않는다. draft·초점·스크롤을 초기화하지 않는다.
- `CommunityBar.tsx`: 8번째 공감 추가 성공과 최대 종류 감지가 서로 다른 버튼으로 초점을 옮기던 경쟁을 수정했다.
- PRD·DESIGN·기존 라운지 spec을 갱신했다. 검색·추가 정렬·필터 기능 구현은 후속 범위다.
