# 보존된 Account Map 데이터 계약

Account Map 앱은 2026-09-15 제거되었습니다. 이 디렉터리는 workspace v5와 구버전 저장값, whole-workspace 백업의 검증·호환성만 지원합니다. UI·편집 command·앱 repository는 제공하지 않습니다. 저장된 `accountMap`과 `locations`는 다른 앱 저장 시 그대로 보존합니다.

[제거 범위와 rollback 계약](../../../docs/superpowers/specs/2026-09-15-account-map-retirement-design.md)을 따릅니다.
